## 这是个什么游戏

1955 年，一位交通大学电机系教授接到迁校通知。你扮演他，走完从上海到西安的这段路——到 1958 年，带着新专业在西安站住脚。

五章，每章一个动作：

1. **争论**　迁校决定下来了，校园里议论四起。三句质疑都是当年真实的说法，你怎么回应。
2. **装箱**　一节车皮，三十五格，能装下的就是以后西安的全部家底。机床、仪器、风琴是异形的，能旋转。
3. **路上**　上海到西安一千五百公里、约四十小时。五个岔路口，选错不掉命，只掉仪器、体力和时间。
4. **建校**　宿舍、教学楼、锅炉房、食堂，人力就那么多，冬天一天天近了，你自己分。
5. **实验室**　1958 年，一台台仪器接通。指针进红区时点"完成调试"，才算真接通。

**全程不会失败**，结局永远是如期开学，区别只在于你带到了多少、建成了多少。每章结束会弹一张史料卡片，一句当年的原话；玩完能生成一张"我的 1956 校园"图，可以直接转发。
